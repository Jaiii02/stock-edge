# 📈 StockEdge

StockEdge is a hybrid stock intelligence platform for Indian equities that combines fundamental analysis, technical analysis, and macroeconomic signals to generate explainable investment recommendations.

Unlike traditional stock screeners that only display financial ratios, StockEdge compares each company against its industry peers and produces an interpretable Buy / Watch / Avoid verdict with supporting reasoning.

---

## 🎯 Project Vision

Help long-term investors answer three questions:

- Is this a good business?
- Is this the right time to buy?
- Why?

---

## ✨ Current Features

- Nifty 500 stock universe
- Industry-based peer grouping
- Fundamental analysis
- Percentile-based scoring engine
- Score out of 10
- Basic Buy / Watch / Avoid verdict
- FastAPI backend
- Live market data using yfinance
